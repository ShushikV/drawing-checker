# Локальные нормативные источники

Положите сюда PDF, к которому у вас есть законный доступ. Импортер читает
исходные байты, но не меняет файл и не копирует его в processed.

Содержимое этой папки, включая PDF, DOCX, TXT и вложенные папки, исключено
из Git. Отслеживаются только этот README и `.gitkeep`. Не применяйте `git add -f`
к нормативным источникам без отдельного решения о правомерности распространения.
Тестовые fixtures в `tests/fixtures/` этим правилом не затрагиваются.

Полная инструкция импорта — в [../README.md](../README.md).
Импорт не подтверждает юридическую или нормативную достоверность документа.
Processed-файлы содержат извлечённый текст: перед их публикацией также нужно
проверить права на распространение.
