# Решения ручной проверки

Эта папка отделена от `processed`: повторный импорт не должен удалять решения
человека или исходные данные, на которых они были основаны.

```text
verified/
  sources/<import-fingerprint>.json
  revisions/<hash-clause-id>/000001.json
  revisions/<hash-clause-id>/000002.json
```

`sources` хранит неизменяемые снимки карточки документа, всех исходных пунктов,
текстов страниц, diagnostics и записи импорта. Снимок создаётся при первом
сохранении решения для данного содержимого импорта и повторно используется.
`revisions` хранит последовательные решения по пункту: исправленный текст,
номер, заголовок, диапазон страниц, статус, оператор, время, примечание,
метаданные и ссылки на source SHA-256, fingerprint импорта и fingerprint пункта.

Хеш в имени папки нужен для переносимости: исходный clause id может содержать
двоеточия, недопустимые в именах Windows. Сам id всегда указан внутри JSON.
Формат — UTF-8, LF, сортированные ключи, отступ 2. Абсолютные рабочие пути
приложение сюда не добавляет. Времена решений являются явно изменяемыми данными.

Файлы существующих ревизий не перезаписываются. Сохранение использует временный
файл и атомарное создание через hard link; требуется файловая система с поддержкой
hard links (например, NTFS). При ошибке публикации старая история остаётся целой.
Неиспользованный снимок источника после неудачного сохранения допустим.

Не редактируйте JSON вручную вместо review-инструмента: это может нарушить
историю и ссылки. Для проверки используйте `python -m app.standards.review_cli validate`.
Хеши обнаруживают несогласованность данных, но не являются цифровой подписью
оператора. Реальные тексты в снимках могут иметь ограничения на распространение;
решение о включении таких файлов в Git принимается отдельно.
